# ZAP Public Dashboard Prototype

Internal static prototype for `task-*zap-dashboard*`.

## Refresh Data

```bash
python3 projects/newsroom/zap-newsletter/files/export-public-dashboard-data.py
```

## Local Preview

```bash
cd projects/newsroom/zap-newsletter/files/public-dashboard
python3 -m http.server 8765
```

Then open `http://127.0.0.1:8765/`.

This prototype should remain internal until Andrew chooses hosting and public branding.

The dashboard reads `../public-dashboard-data.json`, generated by the export script from `zap-applications.db`.
